YNAB Spending Dashboard

A personal, self-hosted spending dashboard for YNAB — charts, a rule-based spending advisor, raw transaction export, and a daily email digest. Runs as a single small Docker container with zero npm dependencies.

Overview

This page documents the project for reference only. The dashboard itself is a private Docker service that runs on a trusted home network and is never deployed publicly — there is no live app, demo, or API behind this page.

The app talks directly to the YNAB API using a Personal Access Token (not OAuth), reads and writes nothing outside your own budget, and keeps all configuration in a local, gitignored .env file.

Features

Dashboard

Spending report over a configurable window (default 30 days): total spent, average per day, spend broken into rule-based buckets, daily/weekly series, top categories and payees.

Charts

Visualizes the same report data for a quicker read on trends.

Advisor

Surfaces spending patterns worth a second look.

Raw export

Every transaction, unfiltered, as JSON or an Excel-friendly CSV download.

Daily email digest

When SMTP is configured, a scheduled job emails a daily summary: yesterday's and last-7-days spend, top payees, spend by bucket, categories over budget, and subscriptions due in the next 3 days — sent via a minimal built-in SMTP client, no mail library.

Auto-categorizer

A standalone script that auto-categorizes uncategorized transactions using the same payee rules, with a --dry-run preview mode.

Transfers, balance adjustments, and credit-card/loan payments are automatically excluded from spend totals so they aren't double-counted.

server.cjs
HTTP server: serves the UI pages plus /api/report, /api/raw, /api/export.csv.
mailer.cjs
Builds and sends the daily digest email over a hand-rolled SMTP client (STARTTLS + AUTH LOGIN).
scheduler.cjs
Schedules mailer.cjs to run once daily at MAIL_HOUR.
index.cjs
Docker entrypoint — starts the server and scheduler together.

Setup

Documented here for reference — this requires your own YNAB personal access token and runs on your own network.

# .env in the repo root
YNAB_ACCESS_TOKEN=your-ynab-personal-access-token

# optional — enables the daily email digest
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=you@example.com
SMTP_PASS=your-smtp-password
MAIL_TO=you@example.com
MAIL_HOUR=7
docker compose up -d

Serves the dashboard at http://<docker-host>:3333/ (maps to container port 3000). If SMTP variables aren't set, the daily digest is simply disabled.

Security

  • The access token grants full read/write access to your YNAB budget. It only ever lives in a local, gitignored .env file.
  • The server has no authentication of its own, so the container is only ever exposed on a trusted home network — never to the public internet.
  • This page is documentation only. No secrets, tokens, or live endpoints are included here or reachable from it.
